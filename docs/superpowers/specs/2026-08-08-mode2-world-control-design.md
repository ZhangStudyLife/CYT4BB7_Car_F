# Car_F Mode2 世界坐标遥控设计

## 目标

车端只使用飞机通过 AirComm 下发的遥控通道。CH4 是所有模式的安全总使能，CH5/CH6 按现有公式 `mode = 3 * ch5_position + ch6_position` 选择 Mode0~8。Mode2 使用 CH0/CH1 控制世界坐标运动方向，以固定目标速度 300 驱动两个有刷电机；所有模式均禁止负压电机启动。

## 实时调度与职责

PIT1 的 100 Hz 中断是所有业务模式的唯一实时控制入口，每个周期按以下顺序执行：

1. 更新编码器反馈并读取 IMU 实时快照。
2. 检查 AirComm RUN_DATA 新鲜度、CH4、IMU 和车辆安全故障。
3. 根据飞机下发的 CH5/CH6 更新当前模式；模式变化时复位旧模式和新模式状态。
4. 公共安全条件不满足时复位当前模式控制状态，执行 `motor_stop()` 和 `negative_pressure_disable()`。
5. 公共安全条件满足时，仍先执行 `negative_pressure_disable()`，再在中断内分发当前模式。
6. Mode2 执行自身控制链路；尚未实现的其他模式直接停止两个有刷电机。

`car_loop` 只负责公共实时调度、传感器采样、AirComm 状态、安全总闸、遥测和模式分发。世界坐标策略、转向策略、速度规划及 PID 状态不再放在 `car_loop.c`。

## Mode2 输入与规划

Mode2 读取 AirComm 已接收的标准化通道，不读取本地遥控协议：

- CH1 映射世界坐标 X 分量。
- CH0 映射世界坐标 Y 分量。
- 摇杆只决定方向，超过进入死区后速度幅值固定为 300。
- 保留旧提交 `e28bcee2731541ded8fd69536781e3a6718dc4a8` 的进入死区 250、退出死区 150 和连续 3 周期确认逻辑。
- 摇杆回中时目标速度为 0，并锁定当前 yaw 作为停止目标。

有效输入通过 `atan2(CH0, CH1)` 得到世界坐标目标航向，并生成世界坐标速度 X/Y。目标航向与车辆当前 yaw 的误差用于生成车体前向速度：误差绝对值达到 90 度时前向速度为 0，小于 90 度时按 `cos(yaw_error)` 缩放。因此差速车先转向再逐渐恢复到固定速度 300，不生成横向车体速度，也不通过倒车缩短转向路径。

## Mode2 控制链路

Mode2 保留并迁入旧提交中的以下逻辑：

1. 世界坐标目标方向与速度生成。
2. 大角度转向的 NORMAL、BRAKE、PIVOT、EXIT 状态机。
3. 转向前减速、换向先减速到零及加减速斜坡规划。
4. yaw 角度外环，输出目标 gyro-z 角速度。
5. gyro-z 角速度内环，输出左右轮差速量。
6. 左右轮目标限幅、编码器速度反馈和左右轮速度 PID。
7. 两个有刷电机的最终 PWM 输出。

Mode2 的 PID 实例、PID 更新函数、世界坐标状态、大角度转向状态和速度规划状态均由 `car_mode2.c` 私有维护。需要菜单调节或遥测观察的参数与诊断量继续保留为全局变量，但定义归属迁到 Mode2。

## 安全与复位

- 上电或故障恢复后仍必须完成 CH4 低到高的重新使能过程。
- AirComm RUN_DATA 超时、CH4 关闭、IMU 故障、安全监测触发或离开 Mode2 时，立即复位 Mode2 的 yaw、gyro-z、左右轮速度 PID 和规划状态，并停止两个有刷电机。
- Mode2 重新进入时从当前 yaw 和零速度开始，不沿用上次目标方向、积分量或掉头状态。
- `negative_pressure_enable()` 和 `negative_pressure_set_throttle()` 不得出现在任何 Mode 的运行路径；公共 100 Hz 安全层每周期执行 `negative_pressure_disable()`。
- Mode0/1/3/4/5/6/7/8 本轮仍为空业务，不允许产生电机输出。

## 验证

- 静态确认本地 CRSF、SBUS 和 WirelessControl 不重新进入控制链路。
- 静态确认 PIT1 100 Hz ISR 每周期判断 CH5/CH6 并分发当前 Mode，后台循环不执行 PID 或电机输出。
- CH4 未使能、AirComm 超时、IMU 故障以及所有空 Mode 下，两个有刷电机和负压电机均停止。
- Mode2 下遍历 CH0/CH1 的前、后、左、右及斜向输入，目标世界方向与旧提交一致，速度幅值固定为 300。
- 摇杆回中后目标速度归零；大于等于 90 度的方向变化先停止平移并完成大角度转向。
- Mode2 退出再进入后，各级 PID 积分、速度规划和大角度转向状态均已清零。
- IAR 9.2 构建 CM7_0 Debug 和受接口变更影响的 CM7_1，要求 0 error。
