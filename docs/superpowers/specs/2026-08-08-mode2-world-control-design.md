# Car_F Mode2 世界坐标差速控制设计

## 目标

Mode2 只使用飞机通过 AirComm 下发的 CH0 和 CH1。CH1 正方向对应车辆上电完成 yaw 归零后的世界 0° 方向，CH0 与 CH1 共同决定世界坐标目标方向。车辆是双轮差速底盘，不生成横向车体速度，而是通过 yaw、gyro-z 和左右轮速度闭环实现世界坐标运动。

CH4 仍是公共安全总使能，CH5/CH6 仍按 `mode = 3 * ch5_position + ch6_position` 选择 Mode0～8。负压无刷电机在所有模式下保持关闭。

## 世界坐标控制

遥控通道已标准化到约 `[-1000, 1000]`。Mode2 在 100 Hz 中断中执行：

1. 计算摇杆模长 `sqrt(CH0² + CH1²)`。
2. 模长不小于 100 时，以 `atan2(CH0, CH1)` 更新世界目标 yaw。
3. 计算 `yaw_error = wrap(target_yaw - current_yaw)`。
4. 普通行驶时，航向误差绝对值达到 90° 则前向速度为 0，否则前向速度为 `2 m/s × cos(yaw_error)`，再统一转换为编码器速度。
5. yaw PD 将航向误差转换为目标角速度，gyro-z PI/FF 将目标角速度转换为左右轮差速量。
6. 左右轮目标为 `base_speed ± turn_output`，统一限幅后分别进入增量式速度 PID。

物理速度通过公共函数按 `1 m/s = 115 cnt` 转换，因此 Mode2 的 2 m/s 对应速度环目标 230 cnt。该投影等价于把世界速度向量投影到车体前向轴，差速底盘无法直接执行的横向分量由转向闭环逐步消除。

## 死区

摇杆模长小于 100 时只把基础速度命令设为 0，并保持上一次目标 yaw。Mode2 不重置 PID、不调用 `motor_stop()`，四个 PID 继续运行，使车轮速度闭环到 0 并维持上一次世界航向。

公共安全总闸不受该规则影响。CH4 关闭、AirComm 超时、IMU 故障或安全故障仍由 `car_loop` 立即复位 Mode2 并停止电机。

## 大角度动态

保留 `e28bcee2731541ded8fd69536781e3a6718dc4a8` 的大角度转向动态：

- 航向误差达到 90° 时锁存目标方向。
- 车辆仍在平移时进入 BRAKE，减速至允许原地转向的速度范围。
- 进入 PIVOT 后基础速度为 0，通过左右轮反向差速原地转向。
- 航向误差降至 35° 后进入 EXIT；摇杆仍匹配锁存方向时，随误差减小逐渐恢复至 2 m/s，即编码器目标 230 cnt。
- 航向误差连续两个周期不超过 3° 后返回 NORMAL。
- 单次大角度转向超过 500 个控制周期时终止，并要求摇杆回到死区后才能重新触发。

保留回中制动前馈、左右轮制动方向锁存和大角度 BRAKE 前馈。普通行驶不使用速度斜坡和加速度前馈，与旧节点中关闭的 `CAR_SPEED_SLEW_AND_ACCEL_FF_ENABLE` 一致。

## 参数与边界

菜单只保留 14 个需要现场调节的参数：左右速度 PID 各 Kp/Ki/Kd、编码器滤波系数、速度静态前馈、yaw Kp/Kd、gyro-z Kp/Ki/Kff/KTurn。

Mode2 目标速度以 `2.0f m/s` 定义，公共速度换算函数集中维护 `115 cnt/(m/s)` 标定系数。死区、轮速上限、输出限幅、前馈过渡和大角度状态阈值使用 Mode2 内部常量。Mode2 只公开安全监测和日志需要的基础速度命令、基础速度目标、左右轮目标及左右电机输出。

## 验证

- CH1 正、CH0 为 0 时目标为世界 0°；CH0 正、CH1 为 0 时目标为世界 +90°。
- 固定摇杆方向并改变车辆 yaw，世界目标方向保持不变，前向速度和差速量随航向误差变化。
- 航向误差为 0°、60°、90° 时，普通阶段前向目标约为 230、115、0 cnt。
- 大角度指令依次经过 BRAKE、PIVOT、EXIT 并恢复 NORMAL。
- 摇杆进入死区后基础速度为 0，目标 yaw 保持，Mode2 不重置 PID、不直接停止电机。
- CH4 关闭、通信超时或安全故障时，公共安全层立即停止全部电机；负压电机始终关闭。
