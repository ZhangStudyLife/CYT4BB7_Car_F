# Car_F Yaw 角度锁定控制设计

## 目标

在现有 100 Hz 角速度内环 `car_gyroz_control_100HZ()` 外增加
`car_yaw_control_100HZ()`。遥控器 yaw 摇杆离开中位时直接控制实际 yaw
角速度；摇杆回中时锁定回中前的当前 yaw。上电 yaw 目标初始化为 `0°`。

## 范围

- 修改 `project/code/Controller/car_loop.c`。
- 修改 `project/code/Controller/car_loop.h`，声明 yaw 外环入口。
- 保留现有角速度内环、左右轮混合、速度环参数和 50 轮速死区。
- 不增加菜单参数，不修改 JustFloat 日志字段，不修改 CRSF 驱动。

## 控制结构

100 Hz 控制顺序为：

1. 根据 `CRSF_STD[1]` 生成基础前后轮速目标。
2. 检查安全开关 `CRSF_STD[7]`。
3. 调用 `car_yaw_control_100HZ()` 生成角速度内环目标。
4. 调用 `car_gyroz_control_100HZ()` 生成左右轮差速修正。
5. 执行左右轮速度环并输出电机 PWM。

`car_yaw_control_100HZ()` 只负责更新 `g_car_gyroz_target_dps`，不直接修改
左右轮速目标。

## 遥控器映射

使用 `CRSF_STD[0]`，范围为 `-1000` 至 `1000`。保留
`-100 < command < 100` 的 yaw 角度锁定区域。离中后先归一化：

```text
u = (abs(command) - 100) / 900
desired_actual_rate_dps = sign(command) * 300 * (0.25 * u + 0.75 * u * u)
```

该曲线在 `±100` 处连续为 `0°/s`，中段响应比纯二次曲线快，两端
快速增长并在 `±1000` 达到 `±300°/s`：

| 通道值 | 实际 yaw 角速度命令 |
| ---: | ---: |
| `±100` | `0°/s` |
| `±200` | `±11.1°/s` |
| `±300` | `±27.8°/s` |
| `±500` | `±77.8°/s` |
| `±700` | `±150.0°/s` |
| `±800` | `±194.4°/s` |
| `±900` | `±244.4°/s` |
| `±1000` | `±300.0°/s` |

## 离中角速度模式

摇杆不在中位时：

1. 按线性与二次混合曲线得到期望的实际 yaw 角速度。
2. 每个周期将 yaw 锁定目标更新为当前 `g_euler.yaw`。
3. 将期望实际角速度送入现有角速度内环。

当前 `car_gyroz_control_100HZ()` 在转换目标时带有负号，而日志确认
`g_euler.yaw` 的变化方向与陀螺角速度方向一致。因此 yaw 外环写入
`g_car_gyroz_target_dps` 时需要补偿该负号，保证 `CRSF_STD[0] > 0` 时
实际 `g_euler.yaw` 增加。

## 回中角度锁定模式

摇杆回中后不再更新 yaw 目标。角度外环采用纯 P 控制：

```text
yaw_error_deg = wrap180(yaw_target_deg - g_euler.yaw)
desired_actual_rate_dps = clamp(2.0 * yaw_error_deg, -300.0, 300.0)
```

再补偿现有角速度内环的目标符号，将结果写入
`g_car_gyroz_target_dps`。

角度误差由目标角度减当前角度得到。因为两者均在正常 yaw 表示范围内，
原始差值只会落在约 `-360°` 至 `360°`。跨越处理规则为：

```text
error > 180°  -> error -= 360°
error < -180° -> error += 360°
```

例如目标 `179°`、当前 `-179°` 时，误差为 `-2°`，车辆走最短方向，
不会旋转 `358°`。

## 状态与初始化

- yaw 锁定目标是 `car_loop.c` 内部静态状态。
- `car_loop_init()` 将 yaw 锁定目标初始化为 `0°`。
- yaw 外环增益固定为 `2.0`。
- yaw 外环实际角速度限幅固定为 `300°/s`。
- 不增加 yaw 外环 I 项或 D 项。

## 安全停机

当 `CRSF_STD[7] == 0` 时：

1. 将 yaw 锁定目标更新为当前 `g_euler.yaw`。
2. 将 `g_car_gyroz_target_dps` 清零。
3. 清零角速度内环 P/I 项、累计输出和历史误差。
4. 执行现有 `motor_stop()` 并返回。

因此重新使能后锁定的是当前朝向，不会突然转回停机前的旧目标。

## 验证标准

静态和公式验证：

- `CRSF_STD[0]` 在 `±100` 处连续为零，在 `±1000` 达到 `±300°/s`。
- 中间映射点符合混合曲线，例如 `±500 -> ±77.8°/s`、
  `±700 -> ±150.0°/s`。
- `CRSF_STD[0] > 0` 时期望实际 yaw 方向为正。
- `179°` 与 `-179°` 两个跨越方向均得到 `2°` 量级最短误差。
- 回中后 yaw 目标保持不变；离中时 yaw 目标跟随当前 yaw。
- 安全停机清零角速度环状态并更新锁定目标。
- `car_yaw_control_100HZ()` 在安全检查后、角速度内环前恰好调用一次。

构建验证：

- `git diff --check` 通过。
- Car_F CM7_0 Debug IAR 构建错误数为 0。

上车验证：

- 上电且摇杆中位时保持 `0°` 基准方向。
- 正负摇杆方向正确，实际角速度随混合曲线连续增长。
- 摇杆回中后锁住回中时朝向。
- 在 `179°/-179°` 附近回中时不发生整圈反转。
- 安全关闭后转动车辆，再重新使能时不回转到旧朝向。

## 非目标

- 不增加自主转向轨迹或 yaw 目标积分模式。
- 不增加 yaw 外环菜单调参。
- 不改变现有角速度内环的 `Kp/Ki/K Turn`。
- 不改变速度环、静态前馈或低目标死区。
