有刷电机速度环：前馈到底在干什么

把前馈理解成“目标速度来了先给一脚估计油门”，PID 只修剩下的小误差。对麦轮底盘，低速不能硬踹静摩擦补偿，所以这里重点对比二次软静摩擦前馈。

仿真参数

有刷电机常用近似

PWM = kS * sign(v) + kV * v + kA * a + PID(error)

kS 管起步摩擦和齿轮阻力，kV 管维持速度，kA 管快速加速。现在代码主要用了 kS + kV，PID 负责误差修正。

响应曲线对比

目标速度 无前馈 硬静摩擦前馈 二次软静摩擦前馈
无前馈

PID 看到速度落后才补 PWM。目标越大，积分越容易累，响应会慢，稳态误差靠积分硬拉。

硬静摩擦前馈

速度目标刚超过 0 就给完整 kS。中高速很有力，但低速容易一脚踹过头，麦轮就会抖。

二次软静摩擦前馈

kS 按速度平方渐入。低速油门轻，中高速再给足补偿，更适合有刷电机加麦轮这种低速非线性强的系统。
